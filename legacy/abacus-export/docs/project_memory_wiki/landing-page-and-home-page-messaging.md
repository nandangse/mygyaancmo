- Home page should take the content and value proposition from the Aarvi x YoungCaesar reference site (see Links); look and feel parked.
- Landing page positioning: audience is "B2B companies" (changed from "B2B manufacturers"). Pain points: dependent on a few employees; agency taking you for a ride; data floating around in Excel (can reach competitors); inconsistency; multiple subscriptions; too many AI credits consumed; needs a rocket scientist.
- Landing "What you gain": control; metrics and KPIs that make sense; real-time reporting; data integrity; more revenue and more profits.
- Hero spells out MQL as marketing qualified lead and states this is the same philosophy that runs multi-million-dollar businesses, now available to you. The landing page has stock photos per section, and a Resources section with a Projection Calculator (lead capture).
- The public landing page must not link to a live tenant (would expose the tenant); the "See a live tenant" button was removed.
- Landing page: latest hero changes and the Tools module (Connect Mail & Import, Find & Merge Duplicates) were in preview and have since gone live with the latest deploy (previously noted as possibly not covered); live Gmail/Outlook sync needs Google/Microsoft OAuth app credentials, not yet configured; manual paste-import into a new list works today.
