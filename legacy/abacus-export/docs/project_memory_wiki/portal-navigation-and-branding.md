- Left menu is a collapsible grouped tree (replaced the flat list): Strategy, Database, Leads, KPIs Dashboard, Reports, Channels (Email, WhatsApp, Social), Company Settings, Credits.
- Expanded/collapsed state of menu groups is persisted per tenant and survives navigation and reload (built in preview 18-Oct-2026, not yet deployed).
- Onboarding page lists the steps to complete and who owns each (Mygyaan AI, Client or Admin), with % completion per section and overall; the overall % also shows in the menu.
- Brand: Mygyaan.ai CMO logo is built from the supplied M-flame mark and full horizontal logo; the mark is used as the icon for now.
- Each company can change its logo in Company Settings (Branding tab).
- In the admin console, companies open in a new tab.
- Portal header is frozen (sticky) while scrolling and co-branded: MyGyaan CMO brand on the left (sidebar corner), tenant logo on the right; the header center shows the current section (page icon, parent group, page name) instead of the ICP sentence. Co-branded header is live; see Status.
- Database group in the menu contains Lists & Contacts, Templates and Sequences.
- Admin Companies screen has a Logo button per company (upload image or paste URL) so a tenant logo such as Nandan's can be set from admin.
